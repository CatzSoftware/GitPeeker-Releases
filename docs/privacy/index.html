GitPeeker 隱私權政策

使用 Google Drive 備份時，GitPeeker 透過 Google Drive API 取得帳號顯示名稱、電子郵件和 Drive 權限識別碼，用於顯示已連接的帳號並核對備份位置。程式以 drive.file 權限存取個別檔案與資料夾。

你選取的儲存庫及 Git 歷史會暫存在本機，接著由桌面程式直接上傳到你擁有且未共用的 Google Drive 資料夾。備份紀錄包含儲存庫識別資訊、Git refs、時間、檔案大小與校驗值。還原時，程式從 Drive 下載資料，在你指定的位置建立新的本機目錄。備份資料與授權憑證不經 CodingCatz 的伺服器。備份檔案未由 GitPeeker 另行加密，程式也不會新增共用權限。

Google 授權憑證在本機使用。若作業系統提供安全的加密儲存，GitPeeker 會加密保存更新憑證及相關帳號資訊。沒有安全的加密儲存時，憑證只保留在記憶體。你可在 GitPeeker 解除連線以移除本機授權憑證，或從 Google 帳戶的第三方連線撤銷 Google 授權。

Drive 備份會保留在你的 Google Drive，直到你透過 Drive 移除它們。解除連線或撤銷授權不會刪除先前的備份。還原到本機的資料由你管理。

本網站使用 Google Analytics 統計瀏覽人數與來源，會在瀏覽器存放 Cookie，記錄造訪的頁面、來源網站、裝置類型與大略地區，不記錄姓名或電子郵件。這只涉及網站，GitPeeker 桌面程式不使用 Google Analytics。你可以在瀏覽器封鎖 Cookie，或安裝 Google Analytics 停用外掛。

GitPeeker 對 Google API 資料的使用與移轉遵循 Google API Services User Data Policy，包括 Limited Use 要求。隱私問題可寄至 catz.software@gmail.com。
