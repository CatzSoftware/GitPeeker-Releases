GitPeeker 服務條款

你可以使用 GitPeeker 預覽及備份你有權存取和複製的儲存庫。請遵守該儲存庫的授權條款，以及你使用的 GitHub 和 Google 服務條款。

備份與還原由你選擇的 Google 帳號和本機位置執行。Git 備份包含可由備份 refs 到達的 Git 歷史。Git LFS 大檔、子模組內容及 GitHub 的 Issues、PR、Wiki、Releases 和設定須另行保存。你可使用還原功能確認備份是否涵蓋所需資料。
