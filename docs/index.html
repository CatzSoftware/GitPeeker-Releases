分支用選的，不用 checkout

工具列選一個分支，檔案清單和預覽就換成那個分支的內容。你電腦上的工作目錄完全不受影響。

同一個檔，三種看法

Markdown 排版成文件，HTML 當成網站，程式碼帶行號。想看它原本長什麼樣，工具列按一下就切過去，不用離開視窗去找編輯器。

切換只改變呈現方式，檔案內容不會被改寫。

文件大綱
打開 Markdown，側欄就換成可搜尋、可收合的標題大綱；捲動時會標出目前讀到哪一節。
多份文件分頁
開過的文件留在上方分頁列，切回去時回到上次讀到的位置。
Mermaid 圖表
流程圖、時序圖在你的電腦上畫出來，不連外部繪圖服務；點一下圖框就能拖曳、縮放、單張放大。
影音可以跳播
儲存庫裡的影片和音訊直接播放，進度條隨意拖。單一檔案上限 16 MiB。
只看內容的全螢幕
按 F11 收起側欄與工具列，整個螢幕留給正在讀的內容。
程式內更新
Windows 版可在程式裡檢查更新，驗證簽章後於背景換版，登入與開著的分頁都保留。

放心用

只要唯讀權限

登入 GitHub 只要求讀取內容的權限，而且只看得到你自己選擇開放的儲存庫。

不經第三方伺服器

內容由你的電腦直接向 GitHub 讀取，私人儲存庫不會被上傳到別的地方。

預覽頁被隔開

儲存庫裡的網頁在隔離的框內執行，碰不到你的登入憑證，也不能自己開視窗或下載檔案。

連同歷史，備份到自己的 DriveBeta

Google Drive 備份功能（Beta）可將你選取的儲存庫及其 Git 歷史備份到自己的 Drive，並從 Drive 還原到本機新目錄。

只有連接備份功能時，GitPeeker 才會請求 Google 授權。它使用 drive.file 權限存取程式在 Drive 建立或取得個別授權的檔案與資料夾。Google Drive 的授權與 GitHub 的授權分開處理。
